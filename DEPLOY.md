# DEPLOY: запуск и публикация сайта levonwb-partner

Это простая инструкция для публикации лендинга Левона Степаняна на Vercel.

## 1. Что находится в проекте

Папка проекта:

`/Users/levonstepanian/Documents/Codex/2026-05-15/wildberries`

Главные файлы:

- `index.html` — сам сайт и тексты.
- `styles.css` — дизайн сайта.
- `script.js` — анимации, слайдер, lightbox и UTM-метки.
- `assets/` — изображения, скриншоты, favicon и preview для соцсетей.
- `package.json` — команды для локального запуска и Vercel.
- `vercel.json` — настройки публикации на Vercel.
- `PROJECT_SUMMARY.md` — подробная память проекта.

## 2. Как запустить сайт локально

Откройте терминал в папке проекта:

```bash
cd /Users/levonstepanian/Documents/Codex/2026-05-15/wildberries
```

Запустите сайт:

```bash
npm run dev
```

После запуска откройте в браузере:

```text
http://127.0.0.1:8080
```

Чтобы остановить локальный сервер, нажмите в терминале:

```text
Control + C
```

## 3. Как проверить проект перед публикацией

Проверка JavaScript:

```bash
npm run check
```

Проверка сборки:

```bash
npm run build
```

Для этого проекта сборка простая, потому что сайт статический: Vercel берет готовые файлы и публикует их.

## 4. Как опубликовать сайт на Vercel

### Вариант через сайт Vercel

1. Зайдите на [vercel.com](https://vercel.com).
2. Войдите в аккаунт.
3. Нажмите `Add New...` или `New Project`.
4. Загрузите проект через GitHub или импортируйте репозиторий, если проект уже загружен туда.
5. Название проекта укажите:

```text
levonwb-partner
```

6. Vercel сам увидит `package.json` и `vercel.json`.
7. Нажмите `Deploy`.

После публикации Vercel выдаст бесплатную ссылку. Желательный адрес:

```text
https://levonwb-partner.vercel.app
```

Если этот адрес занят, Vercel предложит похожий. Название можно поменять в настройках проекта.

### Вариант через Vercel CLI

Если установлен Vercel CLI:

```bash
npm i -g vercel
```

Затем из папки проекта:

```bash
vercel
```

Для продакшн-публикации:

```bash
vercel --prod
```

## 5. Как подключить домен levonwb-partner.pro позже

Когда домен `levonwb-partner.pro` будет куплен:

1. Откройте проект на Vercel.
2. Перейдите в `Settings`.
3. Откройте раздел `Domains`.
4. Добавьте домен:

```text
levonwb-partner.pro
```

5. Vercel покажет DNS-записи, которые нужно добавить у регистратора домена.
6. После подключения домена замените в файлах:

В `index.html`:

- `https://levonwb-partner.vercel.app/`
- на `https://levonwb-partner.pro/`

В `robots.txt`:

- sitemap-ссылку на домен `.pro`

В `sitemap.xml`:

- адрес страницы на домен `.pro`

## 6. Куда вставлять Яндекс.Метрику

В файле `index.html` в блоке `<head>` есть комментарий:

```html
<!-- ВСТАВИТЬ ID ЯНДЕКС.МЕТРИКИ: добавьте код счетчика Яндекс.Метрики ниже перед запуском рекламы. -->
```

Когда Яндекс.Метрика будет создана, вставьте код счетчика рядом с этим комментарием.

Обычно код выглядит как скрипт, который Яндекс выдает в личном кабинете Метрики.

## 7. Куда вставлять Google Analytics

В файле `index.html` в блоке `<head>` есть комментарий:

```html
<!-- ВСТАВИТЬ ID GOOGLE ANALYTICS: добавьте gtag-код Google Analytics ниже при необходимости. -->
```

Когда появится ID Google Analytics, вставьте туда официальный код `gtag`.

## 8. Куда вставлять рекламные пиксели

В файле `index.html` в блоке `<head>` есть комментарий:

```html
<!-- ВСТАВИТЬ РЕКЛАМНЫЙ ПИКСЕЛЬ: добавьте пиксели рекламных систем ниже при подключении площадок. -->
```

Сюда можно добавить пиксели рекламных площадок, если они понадобятся.

## 9. UTM-метки

Сайт уже подготовлен к UTM-меткам.

Пример рекламной ссылки:

```text
https://levonwb-partner.vercel.app/?utm_source=telegram&utm_medium=post&utm_campaign=wb_partner_launch
```

Скрипт сайта сохраняет UTM-метки в браузере пользователя. Позже их можно передавать в форму, CRM или аналитику.

## 10. Как обновлять сайт после изменений

Если сайт подключен к GitHub:

1. Измените файлы сайта.
2. Сохраните изменения.
3. Сделайте commit и push в GitHub.
4. Vercel автоматически опубликует новую версию.

Если публикуете через Vercel CLI:

```bash
vercel --prod
```

## 11. Перед запуском рекламы

Проверьте:

- кнопки ведут в Telegram;
- контакты кликабельны;
- скриншоты кейсов открываются в большом формате;
- сайт корректно открывается на телефоне;
- подключена Яндекс.Метрика;
- подключена нужная рекламная аналитика;
- ссылка в рекламных объявлениях содержит UTM-метки.
